이 폴더에 프로포즈 게임 카드 그림을 넣으면 됩니다.

  back.png            카드 뒷면 (한 장)
  base-01.png ~ 06    기본 카드 (게임 시작 때 모든 사람이 한 벌씩 받음)
  나머지 그림 파일      덱에 들어가는 단어 카드 (예: 001.png, 002.png …)

- 파일 이름은 영문·숫자·-_. 만 사용하세요 (한글·띄어쓰기 X).
- PNG / JPG / WebP, 한 장 최대 5MB. 가로 600px 정도면 충분해요.
- 같은 카드를 여러 장 넣으려면 deck.json 의 "counts" 에 { "023.png": 2 } 처럼 적으세요.
- 그림이 하나도 없으면 deck.json 의 임시 글자 카드(fallbackText)로 게임이 준비됩니다.
- 그림을 바꾼 뒤 게임에서 '게임 선택 → 프로포즈 게임'을 다시 누르면 바로 반영돼요.

# 🃏 테이블탑 카드 — 실시간 멀티플레이 카드 샌드박스

친구들과 같은 테이블에 접속해서 카드를 **직접 집고, 옮기고, 뒤집고, 돌리고, 섞으며** 원하는 규칙으로 노는 웹사이트입니다.
정해진 게임 규칙은 없습니다. PC(Windows)와 휴대폰(안드로이드·아이폰) 브라우저가 같은 방에서 함께 플레이할 수 있어요. (최대 **10명**)

준비된 게임 (방장이 화면 위 🎲 게임 이름을 눌러 고름):
- 💍 **방금 떠올린 프로포즈의 말을 너에게 바칠게** — 가로형 단어 카드, 기본 카드 6장 + 단어 카드 6장. 라운드마다 "프로포즈 받는 사람"만 반지를 줄 수 있고, 반지 3개면 승리 (라운드 진행 자동)
- 🌈 **우노** — **규칙 자동**: 방장이 "▶ 게임 시작"을 누르면 순서를 무작위로 정해 시작, 내 차례에만 낼 수 있음, 스킵·리버스·+2·와일드(색 고르면 그 색 카드로 바뀜)·+4, 뽑기, 1장 남으면 우노! 버튼 경쟁, 승리 판정 (카드는 자체 디자인)
- 🪳 **바퀴벌레 포커** — **규칙 자동**: 64장 분배, 선언하며 넘기기, 진짜/거짓말 대답, 몰래 보고 아직 안 본 사람에게 넘기기, 벌칙 카드, 같은 벌레 4장 패배
- 🂠 **자유 테이블** — 트럼프 54장

- 프론트엔드: React + TypeScript + Vite
- 백엔드: Node.js + TypeScript + Socket.IO
- 저장소: **서버 메모리**만 사용합니다 → ⚠️ **서버를 재시작하거나 다시 배포하면 모든 방과 카드 상태가 사라집니다.**

## 1. 현재 구현 상태

### ✅ 1단계(MVP) — 구현 완료

| 기능 | 내용 |
|---|---|
| 닉네임 / 방 만들기 / 코드 입장 | 6자리 방 코드, 초대 링크 복사(`?room=코드`), 최대 10명 |
| 같은 테이블 실시간 공유 | 입장 즉시 현재 테이블 전체 동기화 |
| 트럼프 54장 덱 | 조커 2장 포함, 서버에서 섞어서 시작 |
| 카드 집기·이동·내려놓기 | 잡은 지점이 커서/손가락 아래 유지, 집으면 떠오르는 효과, 놓으면 그 자리에 고정 |
| 다른 사람의 조작이 실시간으로 보임 | 끄는 도중의 위치를 초당 약 25회 전송 + 받는 쪽에서 부드럽게 보간, 잡은 사람 이름표·커서 표시 |
| 회전·뒤집기 | Q/E 15°, 90°, 더블클릭/더블탭 뒤집기. 뒤집을 때 카드가 실제로 넘어가는 3D 애니메이션 (모두의 화면, 설정의 "카드 움직임 부드럽게"를 끄면 즉시) |
| 카드 겹치기 | 그냥 겹쳐 놓기(시각적 겹침)와 **합치기**를 구분: 더미 위에 놓거나, 낱장 카드끼리 **딱 맞춰(카드 크기 30% 이내)** 놓으면 합쳐져 더미가 됨. 합쳐질 자리는 초록 테두리로 미리 표시 |
| 덱에서 1장 뽑기 | 더미를 끌면 맨 위 1장이 딸려 나옴 / 메뉴에서 손패로 뽑기 |
| 덱 셔플 | 서버에서 암호학적 난수로 섞음, 순서는 누구에게도 전송하지 않음 |
| 비공개 손패 | 소유자에게만 카드 정보 전송, 다른 사람은 장수만 앎 |
| 실시간 상태 동기화 | 위치·앞뒤·회전·더미·잠금 상태를 서버가 최종 결정 |
| 방장 초기화 | 확인창 후 테이블과 모든 손패 초기화 |

### ✅ 2단계 중 미리 구현한 것
여러 장 선택(Shift+클릭, 영역 선택, 모바일 다중 선택 모드) · 여러 장 동시 이동 · 한 줄 정렬 · 더미 만들기(묶기) · 더미 합치기 · 더미 전체 이동(⠿ 손잡이) · 여러 장 뽑기 · 모두에게 나눠주기 · 펼치기 · 더미 뒤집기 · 맨 위로 올리기 · 복제/삭제(권한 확인) · 겹친 아래 카드 선택 · 우클릭/길게 누르기 메뉴 · 확대/축소/이동 · 손패 순서 변경·부채꼴 · 뒷면으로 내기 · 테이블 배경 4종 · 카드 크기 3단계 · 그림자/애니메이션 끄기 · 방장 이전 · 강퇴 · 접속/퇴장 알림 · 재접속 시 손패 복원

### ✅ 게임 도구 (이번에 추가)
| 기능 | 내용 |
|---|---|
| 게임 고르기 (방장) | 프로포즈 / 우노 / 바퀴벌레 포커 / 자유 테이블. 고르면 덱 배치·나눠주기·점수판·타이머까지 자동 준비. 우노·바퀴벌레 포커는 규칙대로만 진행되고(마음대로 카드 내기·옮기기 불가), 프로포즈는 카드를 자유롭게 내되 라운드·반지만 자동 |
| 카드 그림 | `decks/propose/`, `decks/cockroach/` 폴더에 그림 파일을 넣으면 그 그림으로 게임 준비 (4-0 참고). 그림이 없으면 임시 글자 카드 |
| 가로형 카드 | 글씨가 가로인 카드는 테이블·손패 모두 가로로 표시. 손패가 많이 겹치면 두 줄로 펼침 |
| ✍ 직접 쓰는 카드 (프로포즈 게임 전용) | 한 줄에 한 장(최대 30자, 한 번에 20장). 프로포즈 덱에 섞으면 뒷면이 같아서 누가 쓴 카드인지 모름. 내 손패로 바로 받기도 가능 |
| 💍 반지 (프로포즈) | **이번 라운드에 프로포즈를 받는 사람만** 반지를 줄 수 있고, 한 라운드에 1개, 자기 자신에게는 불가 (서버가 확인). 준 뒤 "다음 라운드 ▶" → 테이블 정리, 기본 카드 회수, 단어 카드 6장까지 보충, 받는 사람은 다음 사람으로. 방장은 받는 사람 바꾸기·실수 바로잡기(−/＋) 가능 |
| ⏱ 공용 타이머 | 누구나 시간 설정(10초~5분 버튼 또는 직접 입력, **최대 5분**)·시작·멈춤·처음부터. 서버 시계 기준이라 모두 같은 시간. 마지막 5초 똑딱, 끝나면 알람·진동 |
| 🔊 소리 | 효과음(집기·놓기·뒤집기·섞기·뽑기·나눠주기·반지·승리·입장·타이머) + 배경음악 5곡(편안한·신나는 파티·미스터리·판타지·긴장감). 볼륨: 전체/배경음악/효과음/알림 + 모두 끄기, 이 기기에만 저장. 곡은 방장이 고르면 모두에게 나옴 |
| 더미 꾹 눌러 옮기기 | 더미를 약 0.4초 꾹 누르면 들림 → 그대로 끌면 더미 전체 이동. 모바일에서 움직이지 않고 떼면 메뉴 |
| 빈 더미 자리 | 우노의 "버린 카드"처럼 비어 있어도 사라지지 않는 자리 (카드를 놓으면 합쳐짐) |
| 🔒 잠금 | 카드·더미를 우클릭/길게 누르기 메뉴에서 잠그면 옮기기·뒤집기·회전·삭제·손패로 가져오기가 안 돼요 (끌면 화면만 이동). 잠긴 더미에서 **한 장 뽑기·섞기·나눠주기·카드 쌓기는 가능**하고, 다 뽑아도 빈 자리로 남아요. 잠그기는 누구나, 풀기는 **잠근 사람이나 방장**만. 방장의 "모든 카드 모으기"에서도 잠긴 것은 그대로 |
| 🌈 우노 특수 카드 연출 | 특수 카드를 내면 모두의 화면에 연출 + 소리: 와일드(색 바퀴가 돌다가 고른 색으로, 화면에 색 퍼짐) · 스킵(⊘ 도장 + 건너뛴 사람 이름표 흐려짐) · 리버스(⇄ 회전) · +2/+4 공격(맞은 사람 이름표로 카드가 날아가고 흔들림, 맞은 사람 화면은 빨간 테두리 + 진동). 버린 카드 더미는 늘 지금 색으로 빛나요. "카드 움직임 부드럽게"를 끄면 글자만 잠깐 |
| 🔔 우노! | 누군가 카드가 **1장** 남으면 모두에게 🔔 우노! 버튼이 나와요. **본인이 먼저 누르면 안전**, **다른 사람이 먼저 누르면 1장 남은 사람이 카드 1장을 받아요**. 늦게 누른 사람은 "이미 누군가 먼저 눌렀어요" 안내만 |
| ▶ 게임 시작 (우노·바퀴벌레) | 게임을 고르면 먼저 대기실 → 사람이 다 모이면 방장이 "▶ 게임 시작" (2명 이상). 그때 접속한 사람으로 카드를 나누고 순서를 무작위로 정해요. "다시 하기"도 대기실부터 |
| 🌈 와일드 색 | 와일드를 내고 색을 고르면 버린 카드 더미의 와일드 카드가 **그 색 카드로 바뀌어** 보여요 (덱이 떨어져 다시 섞일 땐 원래 와일드로) |
| 🪳 바퀴벌레 포커 진행 | 차례인 사람이 손패 카드를 탭 → 받을 사람·벌레 고르기 → 가운데에 뒷면 카드. 받은 사람만 🙆 진짜 / 🙅 거짓말 / 👁 몰래 보고 넘기기 버튼 (모두가 본 카드는 넘길 수 없음). 대답하면 카드가 모두의 화면에서 뒤집혀 공개되고, 벌칙 카드가 위쪽 진행 표시줄에 쌓임 |
| 👁 몰래 보기 | 뒷면 낱장 카드를 나만 보기 (자유 테이블 메뉴, 바퀴벌레 포커). 다른 사람에게는 "몰래 봤어요" 알림만 가고 카드 정체는 전송되지 않아요 |
| ⇅ 손패 정렬 | 같은 카드끼리 모이게 손패 정렬 (바퀴벌레 포커처럼 손패가 많을 때) |
| 🫨 잡고 흔들기 | 카드나 더미를 잡은 채 좌우(또는 위아래)로 빠르게 2~3번 흔들면(흔드는 동안 카드가 덜덜 떨려요) 주변(카드 약 3장 거리) 카드가 빨려 들어와 한 더미가 되고, 계속 들고 옮길 수 있어요. 잠긴 카드·게임 카드는 제외 |

> 소리와 배경음악은 음원 파일 없이 브라우저가 직접 만들어 연주합니다 (저작권 걱정 없음). 브라우저 정책 때문에 **화면을 한 번 누른 뒤부터** 소리가 나요.
> 우노 방식 카드는 게임 방식만 참고해 새로 그린 디자인이고, 이름·로고는 사용하지 않았습니다.

### ⏳ 아직 구현하지 않은 것 (완성됐다고 표시하지 않음)
- 웹 화면에서 카드 이미지 업로드 (지금은 `decks/` 폴더에 그림을 넣고 다시 배포), 커스텀 덱 저장/불러오기
- 게임 상태 저장/불러오기 (현재 메모리 전용)
- 방 비밀번호, 강퇴한 사람 재입장 차단 (강퇴된 사람도 코드를 알면 새 플레이어로 다시 들어올 수 있음)
- 남의 손패 일부만 보여주기(공개 손패), 몰래 보기(peek) 같은 세부 규칙 도구
- 서버 여러 대로 확장 (지금은 서버 1대 기준)

> 📐 구조 분석·성능 측정 결과와 새 게임을 추가하는 방법은 **[ARCHITECTURE.md](ARCHITECTURE.md)** 에 정리되어 있어요.

## 2. 프로젝트 구조

```
tabletop-cards/
├─ package.json            ← 루트: 한 번에 설치/실행하는 명령 (npm workspaces)
├─ shared/                 ← 클라이언트·서버가 함께 쓰는 코드
│  ├─ protocol.ts          ← 이벤트 이름, 데이터 형식, 테이블 크기 상수
│  └─ cards.ts             ← 트럼프 54장 / 우노 방식 108장 / 그림·글자 카드 읽기
├─ decks/
│  ├─ propose/             ← 프로포즈 게임 카드 그림 넣는 곳 (README.txt, deck.json)
│  └─ cockroach/           ← 바퀴벌레 포커 카드 그림 넣는 곳
├─ server/                 ← 실시간 서버 (Node.js + Socket.IO)
│  ├─ package.json
│  └─ src/
│     ├─ index.ts          ← 서버 시작, 환경변수, 웹사이트 파일 제공
│     ├─ rooms.ts          ← 방 목록, 입장·퇴장·재접속, 방장 이전·강퇴 (모든 게임 공통 코어)
│     ├─ router.ts         ← 요청 검증·요청 수 제한·응답 형식 (모든 모듈 공통)
│     ├─ modules.ts        ← 기능 모듈 목록 (새 게임은 여기 한 줄 추가)
│     ├─ handlers/
│     │  ├─ sandbox.ts     ← 자유 테이블 카드·더미·손패 이벤트
│     │  ├─ tools.ts       ← 게임 선택, 직접 쓰는 카드, 반지, 타이머, 배경음악, 우노!, 선언
│     │  └─ debug.ts       ← 개발자 측정 (지연 시간, 서버 상태)
│     ├─ room.ts           ← 방 하나의 카드 상태와 모든 조작 로직 (숨김 정보 처리 포함)
│     ├─ presets.ts        ← 게임별 자동 준비 (프로포즈 / 우노 방식 / 바퀴벌레 포커 / 자유 테이블)
│     ├─ decks.ts          ← decks/ 폴더의 그림 카드 읽기 + 그림 파일 제공
│     ├─ metrics.ts        ← 서버 성능 측정 (ENABLE_METRICS=1 일 때만)
│     └─ util.ts           ← id 생성, 셔플, 입력값 검사, 요청 수 제한
│  ├─ test/                ← 기본 테스트 (npm test)
│  └─ scripts/bots.ts      ← 부하 테스트 봇 (npm run bots)
└─ client/                 ← 웹사이트 화면 (React + Vite)
   ├─ index.html, vite.config.ts, package.json
   └─ src/
      ├─ main.tsx, App.tsx ← 시작점, 로비(닉네임/방 만들기/참가), 게임 모드별 화면 선택
      ├─ modes/registry.ts ← 게임 모드 화면 목록 (필요한 화면만 따로 불러옴)
      ├─ perf.ts, PerfOverlay.tsx ← 개발자용 성능 측정 창
      ├─ net.ts            ← 서버 연결, 자동 재접속, 손패 복원
      ├─ store.ts          ← 화면 상태 저장소
      ├─ anim.ts           ← 카드 위치 보간(부드러운 이동)
      ├─ Table.tsx         ← 테이블, 마우스/터치 조작 전체 (가장 중요한 파일)
      ├─ actions.ts        ← 우클릭/길게 누르기/모바일 동작 바가 공유하는 동작 목록
      ├─ CardFace.tsx      ← 카드 앞면·뒷면 그림
      ├─ ui.tsx            ← 상단/하단 바, 메뉴, 설정, 도움말
      ├─ gametools.tsx     ← 게임 바(게임 고르기·타이머·반지·선언·카드 쓰기·소리), 우노 버튼, 몰래 보기 창, 승리 배너
      ├─ sound.ts          ← 효과음·배경음악 (Web Audio로 직접 합성)
      ├─ prefs.ts          ← 이 기기 전용 설정
      └─ styles.css
```

## 4. 인터넷에 배포하기 (친구들이 각자 집에서 접속)

### 4-0. 카드 그림 넣기 (프로포즈 · 바퀴벌레 포커)

**바퀴벌레 포커** — `decks/cockroach/` (세로형 카드)
- `back.png` — 카드 뒷면 1장
- 벌레 8종을 **한 장씩만** 넣으면(예: `cockroach.png`, `rat.png`, `bat.png`, `fly.png`, `toad.png`, `scorpion.png`, `spider.png`, `stinkbug.png`) 종류마다 8장씩 자동으로 64장이 돼요. 64장을 다 찍어 넣으면 그대로 64장.

**프로포즈** — `decks/propose/` (가로형 카드)
1. 카드 그림을 `decks/propose/` 폴더에 넣습니다. (파일 이름은 **영문·숫자·`-` `_`만**, 한글·띄어쓰기 X)
   - `back.png` — 카드 뒷면 1장
   - `base-01.png` ~ `base-06.png` — 모든 사람이 처음에 받는 **기본 카드 6장**
   - 나머지 — 덱에 들어가는 단어 카드 (예: `001.png`, `002.png` …)
   - PNG/JPG/WebP, 한 장 최대 5MB. 가로 600px 정도면 충분해요.
2. 같은 카드를 여러 장 넣으려면 `decks/propose/deck.json`의 `"counts"`에 `{ "023.png": 2 }`처럼 적습니다.
3. GitHub 저장소의 `decks/propose/`(또는 `decks/cockroach/`) 폴더에 그림을 올리면 Render가 다시 배포합니다. 그다음 방장이 🎲 → 그 게임을 고르면 그림 카드로 준비돼요.
4. ⚠️ 시판 보드게임 카드를 스캔한 그림이라면 **친구끼리만** 쓰고, 주소를 공개적으로 퍼뜨리지 마세요. (그림 파일은 주소를 아는 사람이면 열어 볼 수 있어요. 단, 덱의 순서나 남의 손패가 무엇인지는 그림 주소로 알 수 없습니다.)

### ✅ 배포가 제대로 됐는지 확인하기 (중요)
새 기능이 안 보이면 대부분 **서버가 새 코드로 다시 배포되지 않은 것**이에요.
1. 브라우저에서 `https://내주소/version` 을 열어 보세요 → **`2026.11.16-7`** (이 버전)이 나와야 해요. 다른 값이거나 화면이 그냥 웹사이트로 나오면 서버가 예전 코드예요.
2. 게임 안에서도 서버와 화면 버전이 다르면 노란 경고가 떠요. ⚙ 설정 맨 아래에 "버전: 화면 … · 서버 …"가 보여요.
3. Render 대시보드 → 내 서비스 → **Events** 에서 마지막 배포가 "Deploy failed"인지 확인 → **Logs** 에 빨간 오류가 있으면 그 내용을 알려 주세요. 배포가 실패하면 Render는 **예전 버전을 그대로 계속 실행**해요.
4. GitHub에 올릴 때 **새로 생긴 폴더·파일**이 빠지기 쉬워요: `server/src/games/` 폴더(5개 파일), `shared/version.ts`, `decks/cockroach/`. GitHub 저장소 페이지에서 이 파일들이 실제로 있는지 확인하세요.
5. 확실하게 하려면 Render → **Manual Deploy → Clear build cache & deploy**.

### 방법 A (추천): 서비스 하나로 배포 — Render
서버가 빌드된 웹사이트 파일까지 함께 제공하므로 **주소 1개**, **CORS 설정 불필요**, WebSocket 문제도 가장 적습니다.

1. GitHub 계정을 만들고 이 폴더를 새 저장소에 올립니다. (VS Code 왼쪽 "소스 제어" → "GitHub에 게시"를 누르면 쉬워요. `node_modules`는 `.gitignore`로 제외됩니다.)
2. https://render.com 가입 → **New + → Web Service** → 방금 올린 저장소 선택
3. 아래처럼 입력합니다.

| 항목 | 값 |
|---|---|
| Root Directory | (비워 둠) |
| Runtime | Node |
| Build Command | `npm install --include=dev && npm run build` |
| Start Command | `npm start` |
| Instance Type | Free (테스트용) |

4. **Environment** 에 `NODE_VERSION` = `22` 를 추가합니다. (`PORT`는 Render가 자동으로 넣어 줍니다)
5. 배포가 끝나면 나오는 주소(예: `https://my-cards.onrender.com`)를 친구들에게 보내면 됩니다.

⚠️ Render 무료 요금제 주의사항
- 무료 웹 서비스는 15분 동안 HTTP 요청이나 WebSocket 메시지가 하나도 들어오지 않으면 잠자기 상태가 됩니다. 누군가 접속해 있으면 Socket.IO가 주기적으로 신호를 주고받으므로 보통 깨어 있지만, 모두 나가면 잠들고 **그때 방이 전부 사라집니다**. 다시 접속하면 깨어나는 데 수십 초가 걸릴 수 있어요.
- Render는 무료 웹 서비스를 언제든 재시작할 수 있어요. 재시작되면 진행 중인 방도 사라집니다. 오래 안정적으로 쓰려면 유료 요금제를 쓰거나, 나중에 상태 저장 기능(3단계)을 추가하세요.

### 방법 B: 화면과 서버를 따로 배포
예) 화면은 Netlify/Vercel, 서버는 Render.

**서버 (Render Web Service)**
- Build Command: `npm install --include=dev`
- Start Command: `npm start`
- Environment: `CORS_ORIGIN` = 화면 주소 (예: `https://my-cards.netlify.app`, 여러 개면 쉼표로 구분)

**화면 (Netlify 예시)**
- Base directory: (비워 둠), Build command: `npm install --include=dev && npm run build`, Publish directory: `client/dist`
- Environment variable: `VITE_SERVER_URL` = 서버 주소 (예: `https://my-card-server.onrender.com`)
- ⚠️ `VITE_SERVER_URL`은 **빌드할 때** 들어가므로, 값을 바꾸면 화면을 다시 배포해야 합니다.

### 연결 문제 해결 (CORS / WebSocket)
| 증상 | 원인과 해결 |
|---|---|
| 브라우저 콘솔(F12)에 `CORS policy` 오류 | 서버의 `CORS_ORIGIN`에 화면 주소를 **정확히**(https 포함, 끝의 `/` 없이) 넣었는지 확인 |
| `Mixed Content` 오류 | https 화면에서 http 서버로 접속 중. 서버 주소도 `https://` 사용 |
| 계속 "다시 연결하는 중…" | 서버가 잠들었거나 재시작 중일 수 있음. 서버 주소에 `/healthz`를 붙여 열어 보고 `ok`가 나오는지 확인 |
| 회사/학교 와이파이에서만 안 됨 | WebSocket이 막힌 네트워크일 수 있음. Socket.IO가 자동으로 다른 방식(HTTP 폴링)으로 다시 시도하지만, 그래도 안 되면 모바일 데이터로 테스트 |
| 방 코드가 갑자기 "찾을 수 없음" | 서버가 재시작되어 메모리의 방이 사라진 것. 새로 방을 만들어야 함 |

## 6. 직접 확인하는 테스트 방법

PC 1대에서는 Chrome과 Edge(또는 시크릿 창)를 나란히 띄워 A, B로 사용하세요. 휴대폰은 3-4 방법으로 접속합니다.

| # | 테스트 | 확인 방법 |
|---|---|---|
| 1 | 서로 다른 브라우저에서 같은 방 접속 | A가 방 만들기 → B가 코드 입력 → 양쪽 상단 👥 인원이 2 |
| 2 | A가 움직이면 B에 바로 반영 | A가 카드를 천천히 끄는 동안 B 화면에서도 카드가 따라 움직이고 "A" 이름표가 보임 |
| 3 | B가 뒤집으면 A에도 반영 | B가 카드 더블클릭 → A 화면에서도 뒤집힘 |
| 4 | A의 손패를 B가 볼 수 없음 | A가 카드를 손패로 가져감 → B 화면엔 A의 손패 **장수**만 보임. B에서 **F12 → Network → WS(또는 socket.io) → Messages**를 열어 받은 데이터에 A 손패 카드 이름(예: `"H-7"`)이 없는지 확인 |
| 5 | 같은 카드를 동시에 잡기 | A가 카드를 잡고 있는 동안 B가 같은 카드를 끌면 "A님이 잡고 있어요" 알림, 카드는 A만 움직임 |
| 6 | 나갔다 다시 들어오기 | A가 새로고침(F5) → 같은 자리, 같은 손패로 복귀. 휴대폰은 비행기 모드를 잠깐 켰다 끄기 → 자동 재연결 |
| 7 | 두 방이 독립적인지 | 시크릿 창에서 새 방을 만들어 카드 이동 → 다른 방에는 아무 변화 없음 |
| 8 | 확대 상태에서 위치 정확도 | 휠로 확대한 상태에서 카드를 옮김 → 잡은 지점이 커서 아래 유지되고, 확대하지 않은 B 화면에서도 같은 자리에 놓임 |
| M1 | PC 1대 + 휴대폰 1대 | 휴대폰으로 덱을 끌어 1장 뽑기 → PC에 반영 |
| M2 | 안드로이드 + 아이폰 + PC 동시 | 세 기기가 같은 방에서 번갈아 카드 이동 |
| M3 | 서로 다른 네트워크 | 배포 후, 한 사람은 집 와이파이, 한 사람은 모바일 데이터로 접속 |
| M4 | 모바일에서 옮긴 카드 → PC | 휴대폰 한 손가락 드래그 → PC 화면에 같은 위치 |
| M5 | PC에서 뒤집은 카드 → 모바일 | PC 더블클릭 → 휴대폰에 앞면 표시 |
| M6 | 휴대폰 화면 회전 | 가로↔세로 회전 후에도 카드 배치가 그대로, 다른 사람과 위치 일치 |
| G1 | 프로포즈 게임 | 방장이 🎲 → 프로포즈 → 모두 손패 12장, 가운데에 덱 하나 |
| G7 | 🔒 잠금 | A가 덱 우클릭 → 잠그기 → B가 끌어도 안 움직이고 한 장 뽑기만 됨. B는 잠금을 못 풀고 A(또는 방장)는 풀 수 있음 |
| G8 | 🌈 우노 | 방장이 우노 선택 → 대기실 → ▶ 게임 시작 → 순서가 무작위로 표시 → 차례가 아닌 사람이 카드를 탭하면 안내만 → 내 차례엔 낼 수 있는 카드만 밝게 → 와일드는 색 고르기 → 버린 카드 더미가 그 색 와일드로 → 1장 남으면 모두에게 🔔 우노!, 남이 먼저 누르면 1장 받음 |
| G9 | 🪳 바퀴벌레 포커 | 64장 분배 → 차례인 사람이 카드 탭 → 받을 사람·벌레 → 받은 사람이 👁 몰래 보고 다른 사람에게 → 마지막 사람은 대답만 → 카드가 뒤집혀 공개, 벌칙 카드 → 같은 벌레 4장이면 패배 배너 |
| G2 | 직접 쓰는 카드 | ✍ → 두 줄 입력 → 덱에 섞기 → 덱 장수 +2, 다른 사람 F12 Messages에 그 글자가 없음 |
| G3 | 타이머 | A가 10초 시작 → B·휴대폰도 같은 시간, B가 멈추면 A도 멈춤, 끝나면 모두 알람 |
| G4 | 반지 | 받는 사람이 아닌 B는 반지 버튼이 없음 → 받는 사람이 A에게 반지 → "다음 라운드" → 받는 사람 교대 |
| G10 | 🫨 흔들기 | 카드 3장을 가까이 두고 한 장을 잡고 좌우로 빠르게 흔들기 → 3장 더미가 되어 계속 들고 있음 |
| G5 | 더미 꾹 눌러 옮기기 | PC: 더미를 누르고 1초 기다린 뒤 끌기 / 휴대폰: 꾹 누른 뒤 끌기 → 더미 전체 이동 |
| G6 | 소리 | 🔊 → 방장이 "신나는 파티" → 다른 사람도 음악이 나옴, 볼륨 바를 0으로 하면 그 사람만 조용 |

## 9. 알려진 한계

- **메모리 저장**: 서버 재시작·재배포·무료 호스팅 잠자기 시 모든 방이 사라집니다.
- **서버 1대 전제**: 서버를 여러 대로 늘리면 방 상태가 나뉘므로 Redis 어댑터 + 공유 저장소가 필요합니다.
- 카드 충돌(겹침) 판정은 카드 중심점 기준이라, 아주 비스듬히 돌린 카드를 더미에 합칠 때 판정이 살짝 너그럽습니다.
- 손패 카드가 많으면 겹쳐서 표시됩니다 (가로 스크롤 대신 실제 손패처럼 겹침). 가로형 카드는 많이 겹치면 두 줄로 펼쳐지지만, 세로 화면 휴대폰에서 12장 이상이면 글씨 일부가 가려질 수 있어요. 그럴 땐 가로 화면으로 돌리면 한 줄에 다 보여요.
- 타이머는 누구나 조작할 수 있어요 (자유 진행). 장난치는 사람이 있으면 방장이 내보내기로 정리하세요.
- 우노: 공식 규칙 중 "+4 도전"은 서버가 대신 확인하므로(같은 색이 있으면 +4를 낼 수 없음) 도전 단계가 없고, 점수 계산 없이 먼저 다 낸 사람이 승리예요. +2/+4 겹쳐 내기(하우스 룰)는 없어요. 우노 버튼은 요청하신 방식(1장일 때 누르기 경쟁, 남이 먼저면 +1장)이에요.
- 바퀴벌레 포커: 2명이면 공식은 5장 패배지만 4장으로 통일했어요.
- 배경음악은 같은 곡이지만 사람마다 시작 시점이 달라 박자가 정확히 맞지는 않습니다 (각자 기기에서 연주).
- 아이폰은 옆면 **무음 스위치**가 켜져 있으면 웹사이트 소리가 나지 않을 수 있어요.
- 잡고 있는 카드는 15초 동안 아무 움직임이 없으면 자동으로 잠금이 풀립니다. 연결이 끊긴 사람의 잠금은 즉시 풀립니다.
- 방장이 20초 이상 연결이 끊기면 다음 사람에게 방장이 넘어갑니다. 30분 넘게 돌아오지 않은 사람은 자리가 정리되고 손패는 테이블에 뒷면 더미로 내려놓아집니다.
